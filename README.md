# FOXBORO DATABASE — เว็บ

เว็บแทน Power BI report ทำงานแบบ offline ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องต่อเน็ต

## วิธีเปิด

ดับเบิลคลิก **`index.html`** (แนะนำ Chrome หรือ Edge)

ถ้าโดน policy ของเครื่องบล็อกไม่ให้เปิดไฟล์ตรง ๆ ให้ดับเบิลคลิก **`serve.cmd`** แทน
(จะเปิดเว็บเซิร์ฟเวอร์ที่ `http://127.0.0.1:8712` ให้อัตโนมัติ ปิดด้วย Ctrl+C)

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|

## ฟอนต์

ใช้ **SF Compact** ฝังเป็น data URI อยู่ใน `index.html` แล้ว จึงไม่ต้องติดตั้งฟอนต์บนเครื่อง
และเปิดจากไฟล์ตรง ๆ ได้ (Chrome ไม่ยอมโหลด @font-face จากไฟล์ข้าง ๆ บน `file://`)

SF Compact ไม่มีตัวอักษรไทย ข้อความไทยจึงตกไปใช้ Noto Sans Thai / Leelawadee UI
ตามลำดับใน `--font-ui` เบราว์เซอร์สลับให้เองทีละตัวอักษร

`SF-Compact.dmg` เป็นตัวติดตั้งของ macOS เปิดบน Windows ตรง ๆ ไม่ได้
ไฟล์ woff2 ใน `assets/fonts/` แตกและ subset มาจาก .dmg ตัวนั้นแล้ว

## อัปเดตข้อมูล

เมื่อ `FOX DATABASE.xlsx` เปลี่ยน ให้รัน

```
python "03 WEB\build\export_data.py"
```

สคริปต์จะเขียนทับ `data.js` ให้ ใช้เวลาราว 20 วินาที ไม่ต้องแก้ `index.html`

## หน้าจอ

หน้าเดียวจบ ไม่มีแท็บ เรียงจากบนลงล่างคือ KPI 4 ตัว → ตาราง tag records (ตัวหลัก สูง 76% ของจอ)
→ กราฟแท่ง Rows by block type 15 อันดับแรก (คลิกแท่งเพื่อกรอง)

**แถบ FILTER ทางซ้าย** — NAME, DESCRP พิมพ์ค้นหา · AREA, TYPE, CP NAME คลิกเลือกได้หลายอัน ·
CUSTOM COLUMN เลือกคอลัมน์ที่จะแสดงจาก 1,169 คอลัมน์ที่มีข้อมูล
(ตัวเลขข้างชื่อคอลัมน์คือจำนวนแถวที่มีค่าในคอลัมน์นั้น) ค่าเริ่มต้นคือ 10 คอลัมน์หลัก

**ย่อแถบ filter ได้** — กดปุ่มลูกศรกลมที่ขอบแถบ แถบจะยุบเหลือ 76px เหลือแค่ไอคอน
ตารางจะกว้างขึ้น 259px กดไอคอนเพื่อกางกลับ ระบบจำสถานะไว้ให้
ท่าทางเดียวกับที่ใช้ใน PT2 ANALYSIS / ONLINE MONITOR ตั้งใจให้เหมือนกัน
ไอคอนตอนกางอยู่จะขยับเบา ๆ คลิกเพื่อหยุดได้

คลิกหัวตารางเพื่อเรียงลำดับ · ปุ่ม Export CSV ดาวน์โหลดเฉพาะแถวและคอลัมน์ที่กรองอยู่ ·
ปุ่ม ◐ สลับธีมสว่าง/มืด (จำค่าไว้)

## ข้อมูลต่างจาก Power BI ตรงไหน

ทั้งสามข้อคือการแก้ปัญหาที่มีอยู่เดิม ไม่ใช่การเปลี่ยนข้อมูล

1. **77,010 แถว แทน 75,940** — Power Query ทิ้งบล็อก STRING ของ `03CP09`, `31CP01`, `31CP02`
   ไว้ในคอลัมน์ทั่วไป `Column1..Column5` ทำให้ Power BI นับไม่ติด 1,070 แถว
   สคริปต์ย้ายกลับเข้าคอลัมน์จริง (`Column5` ตั้งชื่อเป็น `VALUE`) และตัดแถวหัวตารางที่ปนมา 3 แถวทิ้ง

2. **IOM_ID กลับมาเป็น 6 หลัก** — Excel เก็บเป็นตัวเลขทำให้ `010404` เหลือ `10404`
   สคริปต์เติม 0 ให้ครบ 6 หลักตามที่ `CONVERT 5 TO 6 DIGID.txt` ทำ
   ใช้กับ `IOM_ID`, `IOMIDR`, `DEV_ID`, `PARENT` รวม 2,654 ค่า

3. **AREA ว่าง 13,781 แถว** — `02 AREA\CP AREA.xlsx` มีแค่ 65 CP จาก 87 CP ที่มีข้อมูล
   ยังขาด: `01CP02`, `01CP04`, `01MG01`, `01MG02`, `02CP10`, `161CP1`, `162CP1`, `162CP2`,
   `162CP3`, `162FD1`, `162FD2`, `31CP16`, `31CP19`, `31FD05`, `31FD07`, `31OM01`, `35CP01`,
   `94CP01`–`94CP04`, `94MG02`, `CPTCI1`–`CPTCI3`, `FGMG01`, `FGMG02`
   เติมใน `CP AREA.xlsx` แล้วรัน export ใหม่ ตัวเลขจะหายไปเอง

## เรื่องกราฟ

ของเดิมใน Power BI เป็น pie/donut แต่ TYPE มี 69 ค่า วงกลมที่มีชิ้นขนาดนั้นอ่านไม่ออก
(ในภาพเดิมมีชิ้นเล็กระดับ 0.32% ที่ไม่เห็นเลย) จึงเปลี่ยนเป็นแท่งแนวนอนเรียงจากมากไปน้อย
พร้อมตัวเลขกำกับทุกแท่ง อ่านง่ายกว่าและไม่ต้องพึ่งสีในการแยกแต่ละหมวด

กราฟ Rows by area และตาราง Breakdown ถูกถอดออกเมื่อ 2026-08-28 ตามที่ผู้ใช้ขอ
ให้ตาราง tag records เป็นตัวหลัก และวันเดียวกันได้ยุบหน้า OVERVIEW กับ CUSTOM TABLE
เป็นหน้าเดียวโดยใช้ layout ของ CUSTOM TABLE
ดู `build/table_first_layout.py` และ `build/merge_pages.py` ถ้าต้องการย้อนกลับ
